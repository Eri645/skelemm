 # Skele M&amp;M — Uebsajt statik

 Ky është një uebsajt i thjeshtë, i përgjegjshëm për Skele M&amp;M (furnizim dhe montim skelash në Kosovë), i përkthyer në shqip.

 Skedarët e krijuara:
 - `index.html` — Faqja kryesore
 - `css/styles.css` — Stilet
 - `js/script.js` — JS i vogël klient-side
 - `assets/logo.svg` — Logo shembull

 
 Nëse dëshironi, mund të bëj gjithashtu:
 - Shtoj përkthime shtesë (serbisht ose anglisht) dhe një buton ndërrimi gjuhe.
 - Lidh formularin me Formspree për dërgim pa hapur klientin e postës.
 - Shtoj fotografi shembull për galerinë dhe i optimizoj ato.
